## Project Context

pbf-forge is a comfortable, efficient, and clear tool for downloading OSM/PBF geodata and filtering/processing it. Published publicly on GitHub. Target audience: both GIS beginners and GIS experts.

The repo doubles as a portfolio project, meant to demonstrate skill to potential employers and draw attention. Goal: earn as many GitHub stars as possible while delivering genuine value — not vanity metrics. It should read as thoughtful, detail-oriented, solo-dev work that convinces on its own merits, not as "look at me, give me stars" self-promotion.

Currently 0 stars. No stars badge, no manufactured engagement (fake issues, LinkedIn activity). Realistic target: 100-300 stars in year 1 via organic promotion (OSM forum, r/openstreetmap, awesome-openstreetmap) — see `local/audit/04-competitive.md` for comparables.
