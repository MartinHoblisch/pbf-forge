# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The full text is at that link, and is licensed
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

In short: everyone taking part is expected to behave respectfully, and
harassment of any kind is not acceptable. This applies in issues, pull
requests, commit messages and anywhere else the project is represented.

## Reporting

Report a problem through a
[private security advisory](https://github.com/MartinHoblisch/pbf-forge/security/advisories/new).
It is not what advisories are designed for, but it is the only private channel
this repository has, and it reaches the maintainer without exposing the report
publicly. Mark it clearly as a conduct report.

Reports are read by the maintainer alone, who is also the only person able to
act on them. Whoever is reported will not be told who reported them.

Consequences range from a request to stop, through having a comment removed,
to being blocked from the repository, depending on what happened.
